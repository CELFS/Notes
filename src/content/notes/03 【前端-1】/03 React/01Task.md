## Hook

### 01 useCallback

* `useCallback` 用于缓存函数。
  * 当依赖数组发生变化或不指定依赖数组时，`useCallback` 每次都重新创建，否则不会重新创建，从而使得 props 不发生改变，因此不会重新渲染相应的组件。
  * 依赖数组：添加回调函数内所用变量为依赖项，使得变量值能够伴随回调函数的重新创建而刷新。由于 `useCallback` 只会在初始化时创建一次，从而使用对应作用域的变量初始值，得不到有效的更新，导致非预期的结果（ `setState` 除外）。
* 触发渲染，即组件的代码重新执行一次。

## Redux

### 01 Redux 简介

* Redux
  * A Predictable State Container for JS Apps.
  * 一个专为 JS 应用设计的可预期的状态容器。
  * Store 核心仓库集中管理不同组件中的 State，使得整体状态结构清晰化，简化代码，便于大型应用、复杂项目的构建。
* 状态（State）
  * 一个**变量**，一个用以记录组件状态的变量。
  * 与组件、UI **发生关联**的变量。正如生活中，人有时候谈到 “状态好坏”，其实心里也有一个数值去维护或者衡量。
* 容器（Container）
  * 原本是装东西，延伸为管理东西，状态容器则**存储并管理**状态。
* 可预测（Predictable）
  * 使用容器，标准化、规范化输入，使得不可预期的范围，变为可预期的、可控的、安全的结果。

## React Router

### 01 React Router 简介

* 背景
  * 单页应用 --> 地址跳转（多页模拟，而非多页实现的回头路）
  * 提供一个虚拟页面，使用新组件取代新页面的创建，使得页面元素根据 URL 的解析结果，相应地加载或者移除（本质是之前一个比喻，桌子、物品、工作空间的关系）
* 区别
  * 路径与网页的连接
  * 路径与组件的连接
* 虚拟路由
  * 所有操作都由浏览器在内存中处理，不需要服务器真正加载资源。
* 路由工具
  * 提供虚拟路由，将 URL 地址与组件进行映射。
  * React Router 提供了客户端路由，根据 URL 的变化，自动切换相应的组件（挂载、卸载）。
  * 用户的所有操作，都与 React Router 交互，而不直接访问服务器，除非访问首页。
* 版本
  * React Router 6 相比 5 变化较大。
